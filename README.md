# Frontend Deep Dive

프론트엔드 개념을 **이해하고, 코드로 확인하고, 내 말로 설명하기 위한** 개인 학습 저장소다.

문서를 많이 만드는 것보다 아래 세 가지를 우선한다.

1. 핵심 개념을 한 문장으로 설명한다.
2. 코드의 실행 결과를 원리로 예측한다.
3. 면접과 실무에서 30초 안에 설명한다.

## 현재 학습 순서

```text
실행 컨텍스트
→ 렉시컬 환경과 스코프
→ 클로저
→ var / let / const
→ 호이스팅과 TDZ
→ this
→ 프로토타입
→ 이벤트 루프
```

현재는 JavaScript 실행 모델을 먼저 다진다. React·Vue와 다른 주제는 기반 개념을 설명할 수 있게 된 뒤 확장한다.

> 아직 작성하지 않은 문서는 링크하지 않는다. 다음 문서는 현재 문서를 설명하고 검증할 수 있게 된 뒤 하나씩 추가한다.

## 한 주제를 공부하는 방법

1. 문서의 `먼저 답해보기`에 자료 없이 답한다.
2. 핵심 정의와 예제를 읽고 예상 결과를 적는다.
3. 콘솔과 DevTools에서 결과를 확인한다.
4. 틀린 이유를 한 문장으로 수정한다.
5. `30초 설명`을 자료 없이 말한다.

완료 기준은 “읽었다”가 아니라 문서 마지막 체크리스트를 모두 만족하는 것이다.

## 진행 상황

| 주제 | 상태 | 완료 기준 |
|---|---|---|
| 저장소 운영 규칙 | 정리 완료 | 새 문서를 같은 기준으로 작성할 수 있음 |
| 로컬 개발환경 | 초안 | 실제 프로젝트 기준으로 검증 필요 |
| 실행 컨텍스트 | 학습 중 | 정의·필요성·스택 변화를 설명할 수 있음 |
| 스코프 | 문서 작성 완료 | 선언 위치에 따른 탐색 경로를 그릴 수 있음 |
| 클로저 | 학습 예정 | 환경 참조와 상태 유지를 설명할 수 있음 |
