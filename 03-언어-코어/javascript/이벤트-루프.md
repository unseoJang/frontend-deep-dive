# 이벤트 루프 (Event Loop)

## 이벤트 루프란?

이벤트 루프는 **실행 가능한 작업과 비동기 콜백의 실행 시점을 조정하는 메커니즘**이다.

JavaScript 코드는 일반적으로 하나의 실행 스레드에서 순차적으로 실행되지만, 브라우저는 비동기 작업을 기다리는 동안 다른 코드를 실행할 수 있다.

---

## 왜 필요한가?

타이머나 네트워크 응답처럼 시간이 걸리는 작업을 기다리느라 다른 JavaScript 코드의 실행까지 멈추지 않도록 하기 위해서다.

비동기 작업 자체는 브라우저 등의 실행 환경에서 처리하며, 이벤트 루프는 준비된 콜백이 언제 실행될지 조정한다.

---

## 어떻게 동작하는가?

- **Call Stack**: 현재 실행 중인 함수들의 실행 컨텍스트를 관리한다.
- **Task Queue**: `setTimeout()`, `setInterval()` 등의 타이머 콜백이 실행을 기다린다.
- **Microtask Queue**: `Promise.then()`, `queueMicrotask()` 등의 콜백이 실행을 기다린다.

브라우저의 기본 실행 흐름을 단순화하면 다음과 같다.

```text
현재 Task의 동기 코드 실행
→ Microtask Queue가 빌 때까지 처리
→ 필요하면 브라우저 렌더링
→ 다음 Task 실행
```

마이크로태스크는 다음 태스크를 실행하기 전에 처리된다.

---

## 예시

```js
console.log('start');

new Promise((resolve) => {
  console.log('executor');
  resolve();
}).then(() => {
  console.log('then');
});

console.log('end');
```

**실행 결과**

```text
start
executor
end
then
```

- `start`, `executor`, `end`는 동기적으로 실행된다.
- `then` 콜백은 현재 동기 코드가 끝난 뒤 마이크로태스크로 실행된다.

---

## 헷갈리기 쉬운 점

- `setTimeout(fn, 0)`은 콜백이 즉시 실행된다는 뜻이 아니다. 타이머 지연 조건이 충족된 뒤 별도의 태스크에서 실행된다.
- `Promise`의 **executor는 동기적으로 실행**되지만, `.then()`에 등록한 반응 콜백은 **마이크로태스크로 실행**된다.
- 마이크로태스크는 하나만 처리하고 끝나는 것이 아니라 **큐가 빌 때까지 처리**한다.

---

## 면접 답변

> 이벤트 루프는 JavaScript 실행 환경에서 비동기 작업의 콜백이 실행될 시점을 조정하는 메커니즘입니다. 현재 태스크의 동기 코드가 실행된 후 마이크로태스크 큐를 비우고, 필요하면 렌더링을 수행한 뒤 다음 태스크를 실행합니다. 따라서 Promise의 then 콜백은 일반적으로 setTimeout 콜백보다 먼저 실행됩니다.

---

## 기억할 것

```text
현재 Task의 동기 코드 실행
→ Microtask Queue 비우기
→ 필요하면 렌더링
→ 다음 Task

Promise executor = 동기 실행
Promise.then() 콜백 = Microtask
setTimeout() 콜백 = Task
```
