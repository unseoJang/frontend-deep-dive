# 클로저

## 클로저란?

**클로저(Closure)** 는  
함수와 **그 함수가 선언될 당시의 렉시컬 환경에 대한 참조**의 결합이다.

쉽게 말하면 함수가 만들어진 위치의 바깥 변수에  
**나중에도 접근할 수 있게 하는 성질**이다.

---

## 왜 함수 실행이 끝나도 변수를 사용할 수 있을까?

```js
function createCounter() {
  let count = 0;

  return function counter() {
    count += 1;
    return count;
  };
}

const counter = createCounter();
```

`createCounter()`의 실행은 이미 끝났지만  
반환된 `counter` 함수는 `count`가 존재하는 렉시컬 환경을 계속 참조한다.

```text
counter 함수
    ↓ 참조
createCounter의 렉시컬 환경
    ↓
count
```

따라서 `count`에 계속 접근할 수 있다.

---

## 예시

```js
function createCounter() {
  let count = 0;

  return function counter() {
    count += 1;
    return count;
  };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

`createCounter()`는 한 번만 실행된다.

```text
count = 0

counter()
→ 0 → 1

counter()
→ 1 → 2

counter()
→ 2 → 3
```

반환된 `counter` 함수가 같은 렉시컬 환경의 `count`를 계속 참조하기 때문에 값이 유지된다.

---

## 매번 새로 호출하면?

```js
console.log(createCounter()()); // 1
console.log(createCounter()()); // 1
```

이번에는 `createCounter()` 자체를 매번 다시 실행한다.

따라서 각각 새로운 `count = 0`이 만들어지기 때문에 결과는 `1, 1`이 된다.

---

## 왜 필요한가?

클로저를 이용하면 함수 실행 이후에도 **상태를 유지**할 수 있다.

또한 바깥에서는 직접 접근할 수 없는 값을 특정 함수만 접근하도록 만들 수 있다.

```js
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    return count;
  };
}
```

`count`는 외부에서 직접 접근할 수 없지만 반환된 함수에서는 접근할 수 있다.

---

## 헷갈렸던 점

### 클로저는 단순히 함수 안의 함수가 아니다

```js
function outer() {
  function inner() {}
}
```

이 구조만으로 설명하면 단순한 **중첩 함수** 설명에 가깝다.

클로저에서 중요한 것은:

```text
함수
+
선언 당시 렉시컬 환경에 대한 참조
```

이다.

### 값을 복사해서 저장하는 것이 아니다

```text
바깥 변수의 값을 복사해서 함수에 저장 ❌

바깥 변수가 존재하는 렉시컬 환경을 참조 ✅
```

---

## 면접 답변

> 클로저는 함수와 그 함수가 선언될 당시의 렉시컬 환경에 대한 참조의 결합입니다. 바깥 함수의 실행이 끝나더라도 내부 함수가 그 렉시컬 환경을 계속 참조하고 있다면 외부 변수에 접근할 수 있습니다. 이를 이용해 함수 호출 이후에도 상태를 유지하거나 상태를 외부에서 직접 접근하지 못하게 할 수 있습니다.

---

## 기억할 것

```text
클로저
= 함수 + 선언 당시 렉시컬 환경에 대한 참조

바깥 함수 종료
≠ 바깥 변수에 무조건 접근 불가

내부 함수가 환경을 참조 중
→ 상태 유지
```
