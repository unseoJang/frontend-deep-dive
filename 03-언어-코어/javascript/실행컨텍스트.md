# 실행 컨텍스트

## 한 줄 정의

**실행 컨텍스트(Execution Context)** 는  
JavaScript가 코드를 실행할 때 **현재 코드의 실행 상태를 추적하기 위한 스펙상의 장치**다.

---

## 왜 필요한가?

JavaScript는 코드를 실행하면서 다음과 같은 정보를 관리해야 한다.

- 현재 어떤 코드가 실행 중인지
- 변수와 함수 같은 식별자를 어떤 환경에서 찾아야 하는지
- 함수 실행이 끝난 뒤 어디로 돌아가야 하는지

이런 실행 상태를 관리하기 위해 실행 컨텍스트가 필요하다.

---

## 함수가 호출되면

함수가 호출될 때 새로운 실행 컨텍스트가 생성된다.

```text
함수 호출
↓
실행 컨텍스트 생성
↓
실행 컨텍스트 스택에 push
↓
함수 코드 실행
↓
함수 종료
↓
스택에서 pop
```

---

## 예시

```js
function a() {
  b();
}

function b() {
  console.log("b");
}

a();
```

`b()`가 실행 중일 때 실행 컨텍스트 스택은 다음과 같다.

```text
┌──────────────────────┐
│ b 실행 컨텍스트      │ ← 현재 실행 중
├──────────────────────┤
│ a 실행 컨텍스트      │
├──────────────────────┤
│ 전역 실행 컨텍스트   │
└──────────────────────┘
```

`b()` 실행이 끝나면 `b`의 실행 컨텍스트가 제거되고 다시 `a()`의 실행을 이어간다.

---

## 헷갈렸던 점

### 실행 컨텍스트는 실행 순서 자체가 아니다

실행 컨텍스트는 단순히

```text
1번 코드 → 2번 코드 → 3번 코드
```

와 같은 실행 순서를 의미하는 것이 아니다.

**현재 실행 중인 코드의 상태를 추적하기 위한 장치**다.

### 실행 컨텍스트는 일반 JavaScript 객체가 아니다

JavaScript 코드에서 직접 접근할 수 있는 일반 객체가 아니라  
JavaScript의 실행 과정을 설명하기 위한 **스펙상의 개념**이다.

### 함수에만 존재하는 것은 아니다

함수가 호출될 때 함수 실행 컨텍스트가 생성되지만,  
JavaScript 코드가 처음 실행될 때는 **전역 실행 컨텍스트**도 존재한다.

---

## 면접 답변

> 실행 컨텍스트는 JavaScript가 코드의 실행 상태를 추적하기 위한 장치입니다.  
> 현재 어떤 코드가 실행 중인지와 실행에 필요한 상태를 관리하는 데 사용됩니다.  
> 함수가 호출되면 새로운 실행 컨텍스트가 생성되어 스택에 쌓이고, 함수 실행이 끝나면 해당 실행 컨텍스트가 스택에서 제거됩니다.

---

## 기억할 것

```text
실행 상태 추적
→ 생성
→ push
→ 실행
→ 종료
→ pop
```
