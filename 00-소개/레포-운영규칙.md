# 레포 운영 규칙

## 목적

공부한 내용을 주제별로 정리하고 필요할 때 다시 찾아볼 수 있게 관리한다.

## 운영 원칙

- 한 문서에는 하나의 주제를 다룬다.
- 내용이 길어지거나 다른 주제로 넘어가면 문서를 나눈다.
- 잘못되거나 헷갈리는 설명은 발견하면 수정한다.
- 실제로 존재하는 문서만 `README`에 연결한다.

## 문서 관리

- 파일명은 내용을 알아보기 쉽게 작성한다.
- 같은 설명이 여러 문서에서 반복되면 한곳으로 정리한다.
- 문서 구조는 주제에 맞게 자유롭게 구성한다.
- 작성 중인 문서도 저장할 수 있으며, 처음부터 완성된 형태일 필요는 없다.

## 커밋

하나의 커밋에는 가능하면 하나의 주제나 변경 목적만 담는다.
