# 문서 작성 규칙

## 기본 구조

학습 문서는 아래 구조를 참고하되, 주제에 필요한 항목만 사용한다.

- 한 줄 정의
- 왜 필요한가?
- 동작 방식
- 예시
- 헷갈렸던 점
- 면접 답변
- 기억할 것

모든 항목을 채울 필요는 없다. 짧게 설명할 수 있는 내용은 짧게 끝낸다.

## 작성 원칙

- 정의부터 짧고 분명하게 쓴다.
- 어려운 용어는 쉬운 설명을 함께 적는다.
- 동작 과정은 글보다 코드나 흐름도로 설명하는 편이 쉬우면 그렇게 한다.
- 공부하면서 헷갈렸던 점은 별도 항목으로 남긴다.
- 다른 주제까지 설명이 길어지면 별도 문서로 나눈다.

## 표현 규칙

- 제목은 `#` 하나만 사용한다.
- 섹션은 `##`, 하위 섹션은 `###`까지만 사용한다.
- 한글 용어와 영문 용어는 처음 한 번만 함께 쓴다.
- 확실하지 않은 비유나 오해를 만들 수 있는 표현은 피한다.
