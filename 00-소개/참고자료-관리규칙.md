# 참고자료 관리 규칙

## 목적

공부할 때 참고한 자료를 나중에 다시 찾을 수 있게 기록한다.

## 자료 선택

- 공식 문서와 신뢰할 수 있는 자료를 우선한다.
- 개인 블로그나 영상도 참고할 수 있지만 중요한 내용은 다른 자료와 함께 확인한다.
- 검색 결과의 요약만 보고 내용을 단정하지 않는다.

## 기록 방법

실제로 참고한 자료만 문서 아래에 남긴다.

```text
- 자료명 — URL
```

필요한 경우에만 간단한 설명이나 버전을 함께 적는다.

```text
- 자료명 — URL
  - 참고한 내용: 간단한 설명
  - 버전: 버전에 따라 내용이 달라질 때만 작성
```

## 관리

- 사용하지 않은 링크를 참고자료 수를 늘리기 위해 추가하지 않는다.
- 링크가 사라졌다면 가능하면 대체 자료로 변경한다.
