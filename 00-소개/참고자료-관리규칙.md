# 참고자료 관리 규칙

## 목적

링크를 모으는 데 그치지 않고, **어떤 설명의 근거로 사용했는지 다시 찾을 수 있게** 관리한다.

## 우선순위

1. 표준과 명세
2. 공식 문서
3. MDN 같은 관리되는 레퍼런스
4. 근거와 재현 과정이 있는 기술 글
5. 개인 블로그·영상은 교차 검증 후 사용

## 문서에 남길 정보

각 문서의 `참고자료`에는 실제로 사용한 자료만 적는다.

```text
- 자료명 — URL
  - 사용 이유: 어떤 정의나 동작을 확인했는지
  - 확인일: YYYY-MM-DD
```

## 확인 규칙

- 프레임워크·도구 문서는 버전과 확인 날짜를 남긴다.
- 표준 개념도 링크가 유효한지 문서를 수정할 때 확인한다.
- 출처마다 용어가 다르면 ECMAScript 명세 용어를 기준으로 차이를 설명한다.
- 링크가 사라지면 대체 자료를 찾고, 찾지 못하면 해당 설명의 확실성을 낮춰 표시한다.

## 금지 사항

- 읽지 않은 링크를 참고자료 수를 늘리기 위해 추가하지 않는다.
- 검색 결과 요약만 근거로 단정하지 않는다.
- 개인 글 하나만으로 언어 동작이나 보안 결론을 확정하지 않는다.
